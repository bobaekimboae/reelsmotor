# ReelsMotor

ReelsMotor는 자동차·부동산·상품 사진으로 9:16 세로 영상을 만드는 한국어 웹앱입니다. GitHub Pages에서 동작하며 사진과 입력한 정보는 이 앱의 브라우저 안에서 처리됩니다.

## 사용 방법

1. `https://bobaekimboae.github.io/reelsmotor/`에 접속합니다.
2. 자동차를 선택하고 사진을 3장 이상, 최대 10장까지 추가합니다. 사진 순서는 업로드한 순서대로 영상에 들어갑니다.
3. 제조사, 모델, 연식과 선택 정보를 입력합니다.
4. 볼드·클린·다이내믹 중 스타일을 고르고, 필요하면 상호명·로고·전화번호·색상을 추가합니다.
5. 이메일 칸을 입력하고 `내 영상 만들기`를 누릅니다. 이 정적 버전은 이메일을 저장하거나 전송하지 않습니다.
6. 브라우저에서 생성된 MP4를 미리 재생하고 다운로드합니다.

## 영상 생성

영상은 Mediabunny와 브라우저 WebCodecs를 사용해 H.264 MP4로 인코딩합니다. 해상도는 720×1280(9:16)이며, 사진마다 4초 장면을 만듭니다. 최신 Chrome 또는 Edge를 권장합니다. 기기에서 WebCodecs 인코딩을 지원하지 않으면 다른 브라우저에서 시도해 주세요.

## 배포

`main` 브랜치에 변경 사항을 푸시하면 GitHub Actions가 Vite 앱을 빌드해 GitHub Pages에 배포합니다. 저장소 Pages 설정은 GitHub Actions를 소스로 사용해야 합니다.

## 현재 범위

영상 생성·미리보기·다운로드는 브라우저에서 실제 동작합니다. 원본 ReelsMotor의 계정 로그인, 이메일 발송, 유료 결제, 영상 저장소, 소셜 계정 연결 및 자동 게시 API는 GitHub Pages 정적 사이트에 연결되어 있지 않습니다.
