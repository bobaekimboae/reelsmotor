# 릴스모터스 — 중고차 숏폼 메이커

중고차 사진과 매물 정보를 조합해 쇼츠·릴스용 세로 영상을 만드는 한국어 웹 앱입니다.

## 사용 방법

1. [릴스모터스 웹 앱](https://bobaekimboae.github.io/reelsmotor/)을 Chrome 또는 Edge에서 엽니다.
2. 차량 사진 3~10장을 추가하고 첫 장면이 될 사진을 맨 앞으로 정렬합니다.
3. 차량명, 연식, 주행거리, 가격, 매장명 등 영상에 넣을 정보를 입력합니다.
4. 스타일, 화면 비율과 영상 길이를 선택합니다. 9:16, 8초·12초·20초를 지원합니다.
5. MP4 영상 만들기를 눌러 생성하고, 미리보기에서 확인한 뒤 파일을 사용합니다.

## 기능

- JPG, PNG, WebP 사진 업로드, 끌어놓기, 순서 변경 및 삭제
- 스튜디오·골든아워·시티 나이트 스타일
- 차량 정보, 문구, 매장 정보 끝 카드 합성
- 9:16 등 여러 화면 비율, 8초·12초·20초
- 브라우저에서 H.264 MP4 생성, 미리보기 및 다운로드
- 사진을 서버에 올리지 않고 기기에서 처리

## 기술 및 제한

정적 웹 앱으로 GitHub Pages에서 제공합니다. MP4 인코딩에는 Mediabunny 1.65.0을 jsDelivr에서 불러와 사용합니다. 첫 MP4 생성 시 인터넷 연결과 브라우저의 WebCodecs/H.264 인코더 지원이 필요합니다. 미지원 환경에서는 WebM으로 저장될 수 있으며 SNS 호환을 보장하지 않습니다.

AI 음성·생성형 영상, 배경 음악, 로그인, 이메일 발송, SNS 자동 게시 기능은 포함하지 않습니다.
