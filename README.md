# 릴스모터스 — 중고차 숏폼 메이커

중고차 매물 정보를 입력하고 사진을 편집해 쇼츠·릴스용 영상을 만드는 한국어 웹 앱입니다.

## 사용 방법

1. [릴스모터스 웹 앱](https://bobaekimboae.github.io/reelsmotor/)을 Chrome 또는 Edge에서 엽니다.
2. 제조사와 모델을 입력하고 연식, 주행거리, 가격, 차량 설명과 문의 문구를 추가합니다.
3. 사진 4~30장을 올린 뒤 표지 사진과 순서를 정합니다.
4. 화면 비율과 길이를 고르고, 필요한 경우 권리 보유 음악 파일을 추가합니다.
5. MP4 영상을 만들고 미리보기에서 확인한 뒤 다운로드합니다.

## 기능

- 제조사·모델, 매물 ID, 연식, 주행거리, 가격, 차량 설명 입력
- 시승 예약·차량 문의·견적 요청·방문 예약 등 문의 문구와 사용자 지정 링크
- JPG, PNG, WebP 사진 4~30장 업로드, 사진당 최대 50MB
- 표지 지정, 사진 순서 변경 및 삭제
- 9:16, 1:1, 16:9 화면 비율과 8초·12초·20초 길이
- 스튜디오·골든아워·시티 나이트 영상 스타일
- 사용자가 제공한 음악을 영상 길이에 맞게 반복·페이드해 MP4에 합성
- 사진과 음악을 브라우저에서 처리하며 서버에 업로드하지 않음
- H.264 MP4 생성, 지원되지 않는 환경에서는 WebM으로 대체

## 제한

정적 웹 앱이며 로그인, 서버 저장 프로젝트, 공유 랜딩 페이지, 문의/리드 대시보드, 모바일.de·AutoScout 연동은 제공하지 않습니다. 음악을 사용하려면 파일을 추가해야 하며, 사용 권한이 있는 음원만 선택하세요. MP4 인코딩은 WebCodecs와 기기의 H.264/AAC 지원이 필요합니다. 첫 MP4 제작 시 인코더를 내려받기 위해 인터넷 연결이 필요합니다.
